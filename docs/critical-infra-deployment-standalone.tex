\begin{abstract}
This note demonstrates that the offline STARK-DNS epoch-package
architecture is empirically practical for sub-TLD critical-infrastructure
DNS deployment.  At realistic deployment scopes (\texttt{.gov},
\texttt{.mil}, allied government TLDs, NATO/ICS-CERT critical-sector
endpoint lists), the epoch package is \SI{3}{\mebi\byte}--\SI{30}{\mebi\byte},
boot cost is \SI{10}{\milli\second}--\SI{16}{\milli\second}, and
per-query cost is \SI{6}{\micro\second}--\SI{9}{\micro\second}.  Every
projection is anchored by measured data points on real Swedish
\texttt{.se} DNSSEC captures committed to the implementation repository.
The architecture is post-quantum secure and requires no network
connectivity after the one-time epoch acceptance.
\end{abstract}
